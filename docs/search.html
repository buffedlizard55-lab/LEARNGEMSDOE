One box over every research entry, hypothesis card and page · generated from research/ by scripts/build_search_index.py

Search the knowledge base

Type anything — a band number, a method, a rules section, an author, a phrase like "pixel-exact" or "400 m". The index is built from the markdown mirrors, so a hit links straight to the entry on its page.

    How this index is built

    scripts/build_search_index.py reads every markdown mirror in research/, splits it into numbered entries, and pulls the <title> and description out of every page under docs/. It writes docs/assets/search-index.js. Nothing is fetched and no data is downloaded — the index is committed, and it is regenerated with: 

    python3 scripts/build_search_index.py          # regenerate
python3 scripts/build_search_index.py --check  # fail if the committed index is stale

    If search results look out of date, run the first command and commit the regenerated file. The site also runs scripts/check_site.py to confirm that internal links resolve and that every external link points at a source recorded on the sources page.
