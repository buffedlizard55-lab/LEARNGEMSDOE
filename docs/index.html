Find the faults the catalogue missed

The GEMS Prize is not scored on reproducing the published fault map — that map is masked out of scoring. It is scored on faults that experts identified and that are absent from the USGS / INGENIOUS catalogue in the GeoDAWN area. This site is the research library and hypothesis backlog behind that problem: every entry cites a primary source you can open and check.

What is actually being scored

Private test set for Phase 1 was labelled by experts before competition and is fixed. In Phase 2 an expert panel reviews every team's submission, verifies genuinely new faults, and all submissions are re-scored against expanded set — so a prediction that helps experts find a real unmapped fault can score higher in Phase 2 than Phase 1 (competition structure).

Two clarifications from DrivenData staff change optimal strategy materially, quoted verbatim on governance:

  1. Existing catalogue pixels are masked from evaluation in both rounds — mask is pixel-exact, not buffered.
  2. A new-fault ground-truth pixel may lie within 300 m of a known trace; staff describe finding those corrections as “one outcome we are aiming for”.

Net effect: reproducing catalogue earns nothing, hedging wide corridor around known traces costs real false-positive mass. Money is in geometry an expert would add — tip extensions, splays, parallel strands, structures under cover — not thicker ink on mapped lines.

Each is a place where official documents disagree, or where a question put to organisers has no answer. Open links to verify.

  1. Deadline wording differs. Hub: “Dec. 3, 2026, 11:59 p.m. UTC”; rules §A.1: “5:00 p.m. ET on prize submission deadline date”. Both official. Treat earlier instant as binding. (hub · §A.1)
  2. Eligibility text shorter on homepage than in rules. Hub says captain must be US citizen/PR; §1.3 adds team members must be legally authorized to work in US, excludes FFRDC-affiliated researchers from cash, excludes MFTRP participants, defines FCOC including Iran/North Korea/Russia/Belarus/China. Forum threads 11540, 11526, 11499 unanswered.
  3. Test-fault provenance will not be published. Staff: “We're not sharing details about data sources, fault types, or coverage behind test faults beyond what's in problem description.” (11527 post 7)
  4. Reference notebook prints label raster as “Band 19”. Staff confirm bug in summary string; label file has one band. (11529)
  5. Feature-stack provenance not documented per band. 19-band raster carries band descriptions and data categories, but competition pages do not state which public release each band derived from, at what resolution resampled, or how nodata handled. Any provenance claim beyond band description is inference and labelled as such.
  6. No training pipeline in this repository. A prior handoff stated train→inference→validate pipeline was “ready to run”; it is not present in scripts/. Only metrics verified. See pipeline status. Re-checked this session: still true. This agent did not add one — gated by design.
  7. Rules PDF host redirect. Official URL nlr.gov/docs/fy26osti/96647.pdf redirects to docs.nlr.gov when fetched on 2026-09-26. Keep NLR URL as citation. Change-log table in PDF preface still empty.
  8. Staff about-post links to page 966. Pinned forum welcome links to page 966, duplicate of hub welcome, not problem description page 967.
  9. Public downloads failed TLS from this machine; not treated as missing. curl to usgs.gov, sciencebase.gov, gdr.openei.org returned SSL_ERROR_SYSCALL. HTML/JSON readable via separate fetch path. ScienceBase catalog lists outline zips. Do not conclude absent.
  10. Catalogue attribute conventions mixed. On NBMG service, MAPSCALE stores both short codes and literal string 1:10,000, and REC2023 stores both <15,000-style bins and bare numbers such as 8400. Do not normalize until field-definition text read. Counts: requirements page.
  11. Two instructions for how much area GeoTIFF must cover. Rules §3.2 says “for entirety of GeoDAWN study area”; problem description says “same bounds as training data”. Grid bounding box ~2.4× surveyed area, so not obviously same. Unresolvable until raster placed — GV-12.
  12. Official documents disagree about whether GeoDAWN includes lidar. Rules §2 calls it “a high-resolution lidar, magnetic, and radiometric study”; data release titled “Airborne magnetic and radiometric surveys” and describes 3DEP lidar as coordinated but separate collection.
