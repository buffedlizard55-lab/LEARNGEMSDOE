Find catalogue gaps, not known traces

Research library for the Geologic Enhanced Mapping System (GEMS) Prize. The scored target is faults that are not already in the USGS / INGENIOUS catalogue in the GeoDAWN area. This site documents sources, methods, and hypotheses. It does not generate or submit predictions.

Training blocker (verified): competition GeoTIFFs sit behind DrivenData login (data tab → login). Place them with bash scripts/download_competition_data.sh on an unrestricted machine, then python scripts/prepare_data.py. This agent does not use weekly submission slots.

Hypothesis backlog (status)

All hypotheses below are untested — no spatial holdout has been run in this repository because competition rasters are not placed. Full cards: hypothesis backlog.

  • H1 — Along-strike extensions and splays of mapped traces (pixel-exact mask; 300 m kernel can still score nearby new geometry).
  • H2 — Intra-basin buried structures from gravity/magnetic edges under cover that QFFD never intended to map.
  • H3 — 1 m lidar scarps too subtle or too recently imaged for the compiled catalogue.
  • H4 — Strain-rate / seismicity highs with no catalogue trace.
  • H5 — Do not reproduce the training label raster; the reference U-Net is trained on the catalogue that scoring masks out.
