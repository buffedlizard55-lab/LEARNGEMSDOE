Research library

Six domains. Entries are numbered so they can be cited from the hypothesis cards, the changelog and the AI-usage log without re-explaining themselves. Anything that cannot be traced to a primary or clearly authoritative source is marked unverified or inference — it is never presented as fact.

Confidence vocabulary

MarkMeaning
verifiedRead directly out of the linked primary or clearly authoritative source this session, usually as a verbatim quotation.
unverifiedThe source exists and is linked, but the specific content has not been read or confirmed. Often a paywalled paper whose abstract or record only is confirmed.
inferenceOur reasoning from verified inputs. Stated so a geologist can argue with it. Not a sourced claim.
staffA DrivenData staff forum answer — authoritative about the platform, not about geology.
rulesFrom the official rules PDF, by section number.

How to extend an entry

  1. Open the primary source and quote it. Do not paraphrase a secondary summary.
  2. Add to the existing entry; do not create a second entry for the same source. Entries are idempotent by ID.
  3. Change the confidence mark only when the underlying content has actually been read.
  4. Append a dated line to the changelog and, if generative AI was involved, a dated block to the AI-usage log.
  5. Update the markdown mirror in research/ at the repository root so the diff is reviewable.
