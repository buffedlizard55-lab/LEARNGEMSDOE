Corrections made this session

Recorded so the change is visible rather than silent:

It had been listed with no verified content, so it was moved out of the citation index; the PDF was then opened, found to be a real GBCGE / NBMG paper with a directly relevant statement about how the INGENIOUS fault database was collated, and restored to the methods table above as abstract and introduction read.

Repository artefacts

  • scripts/metrics.py — distance-weighted Tversky index, Tversky loss, and a masked variant. Self-tests run on CPU with the standard library only.
  • scripts/prepare_data.py — inspection-only raster inventory; writes data/inventory.json.
  • scripts/download_competition_data.sh — prints the official URLs and checks data/; does not log in and stores no credentials.
  • research/*.md — markdown mirrors of the library, so changes are reviewable as a git diff.
