Corrections made this session

Recorded so the change is visible rather than silent:

  • “Hart-Wagoner et al., GRC feature engineering” was demoted and then reinstated. It had been listed with no verified content, so it was moved out of the citation index; the PDF was then opened, found to be a real GBCGE / NBMG paper with a directly relevant statement about how the INGENIOUS fault database was collated, and restored to the methods table above as abstract and introduction read.
  • Kreemer “et al.” corrected to Kreemer & Young, and Siler's initials to D.L., using the INGENIOUS project page's own publication list.
  • PA-2's epoch-resolved Hermant figures superseded (2026-09-26, session arena/01a0df88). PA-2 recorded PR-AUC ≈ 0.88 train / ≈ 0.59 validation for FaultSEG “at epoch 17.5”, taken from a figure whose axis labels were truncated in our extraction. §6 states the values in prose: FaultSEG 0.902 / 0.610 / 0.595 (train / validation / test) and siUNET 0.574 / 0.463 / 0.449. The prose values now appear as PA-6 and should be cited instead. The old numbers were not fabricated, but they were read off a chart and labelled with a precision the source does not support.

Repository artefacts

  • scripts/metrics.py — distance-weighted Tversky index, Tversky loss, and a masked variant. Self-tests run on CPU with the standard library only.
  • scripts/prepare_data.py — inspection-only raster inventory; writes data/inventory.json.
  • scripts/download_competition_data.sh — prints the official URLs and checks data/; does not log in and stores no credentials.
  • research/*.md — markdown mirrors of the library, so changes are reviewable as a git diff.
  • scripts/build_search_index.py — generates docs/assets/search-index.js from the markdown mirrors and page metadata. --check fails if the committed index is stale.
  • scripts/check_site.py — offline site verification: internal links and anchors resolve, local assets exist, and every external link on the site is recorded as a source on this page. It fetches nothing.
