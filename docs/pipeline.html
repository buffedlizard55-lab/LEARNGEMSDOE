Data placement and pipeline gates

Single remaining blocker to any local training: competition rasters are not in this repository. The DrivenData data tab requires login (verified redirect). This sandbox cannot complete that download.

On an unrestricted, enrolled machine

bash scripts/download_competition_data.sh
python scripts/prepare_data.py

download_competition_data.sh does not scrape DrivenData. It prints the official URLs, checks for files already in data/, and exits 2 if they are missing. Credentials are never stored in git.

prepare_data.py opens GeoTIFFs if present, reports CRS/resolution/size/bands, and writes data/inventory.json. It refuses to write a prediction raster.

What is intentionally not here

  • No inference script that emits a submission GeoTIFF.
  • No DrivenData API submitter.
  • No copy of the Lipor notebook’s training loop (link only: reference solution).

After data placement, a separate, explicitly gated process may train. GPU is required for a serious U-Net run (reference README). Metric definition lives on the problem description; this agent does not claim a local DTI implementation has been numerically verified against DrivenData’s scorer (that would require labels we do not have).
